# Brightpaw

Brightpaw is a fictional dog-walking business in Austin, Texas. It is the demo business in [Creli](https://creli.ai): open the demo and you see three weeks of Brightpaw's work, from the owner's one-line idea to a running business.

This repository is Brightpaw's website, built by Creli's agents in that story. Nadia planned it, Ines designed it, Marcus built it and Quinn tested it; the pull requests and issues here are theirs. Brightpaw, its customers, walkers, prices and numbers are made up.

## What is here

- `index.html`, `pricing.html`, `book.html`, `about.html` and `site.css`: the site, plain HTML and CSS
- `booking.js`: the booking form. It checks the phone number, keeps your choices when a field needs fixing and shows a confirmation. There is no server behind it, so nothing is sent.
- `*.test.js`: the tests, run with `npm test` (Node 20 or newer)
- `brand/` and `fonts/`: the logo and the self-hosted fonts

The site is live at https://brightpaw.dw3tr.com.
